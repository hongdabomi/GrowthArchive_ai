# Growth Archive AI

Growth Archive는 대화와 자료를 활동별 기록으로 모으고, 기록에 남은 근거를 바탕으로 경험의 변화와 성장을 돌아보는 서비스입니다. 이 저장소는 서비스의 **Python/FastAPI AI 서버**입니다.

## AI가 하는 일

- 홈 채팅에서 글·파일·링크를 읽고 활동 연결, 기록 요약, 주요 변화를 제안합니다.
- 한 활동에 쌓인 기록을 종합해 활동 정보의 초안을 만듭니다.
- 확정된 기록을 비교해 Journey의 성장 유형과 판단 이유를 제안하고, 원문 인용 근거를 연결합니다.
- 파일을 제외한 뒤 남은 자료만으로 분석을 다시 수행합니다.

성장 판단은 **능력 확장·성과 향상·경험 축적·효율성 향상·경험 전이**의 다섯 유형을 사용합니다. 확인할 근거가 부족하면 성장을 단정하지 않습니다.

AI 서버는 OpenAI를 호출해 분석 초안을 만듭니다. 작업과 원본 자료를 보관하고, 사용자가 확정한 활동·기록·Journey를 저장하는 일은 별도 백엔드가 담당합니다.
